身份與唯一 treatment
--------------------

架構：PlayerV5（code class ``PlayerRankedTopK``；checkpoint architecture
key ``player_ranked_topk``）。Promotion status：candidate。所有
snapshot／periodic／final checkpoint 一律 ``experimental=true``、
``production_compatible=false``、``promotion=false``。

兩臂都是 aux retention、scripted Spawner、同一 optimizer 設定、
同一 seed、同一 rollout window、同一 seed-5 BC、同一 teacher、
同一 dataset、同一 eval、同一 corrected bootstrap。不是 aux 對無 aux，
也不是 equal-frame／equal-optimizer-step。

**唯一 treatment**：折扣視野。

- control：``gamma=0.99``、``lambda=0.95``（``gamma*lambda=0.9405``）
- long：``gamma=0.9995``、``lambda=0.999``（``gamma*lambda=0.9985005``）

Gamma 與 lambda 一起改。只加長 gamma、把 lambda 留在 0.95，不是本契約。
不混入 entropy、learned Spawner、self-play、DAgger、equal-compute、
critic warmup、action repeat／frame skip、reward 改寫或第二個 PPO seed。

此 control 不是歷史 Phase 3 aux 的重跑：歷史 run 把 4200 截尾當
terminal 且 bootstrap 為 0。本輪兩臂都改用下方 bootstrap。不得把本
control 與 ``1789696064`` 或 seed-11 confirmatory 當成同一條軌跡。

Corrected post-step V bootstrap（兩臂相同）
-------------------------------------------

Rollout cap 仍是 4200 frames。Reward 沿用現行 ``shaped_reward``：真死
（``done and env.dead``）才減 1；截尾不加死亡罰。不改 reward。

- 真死：延續 mask 為 0，bootstrap value 為 0。``last_value`` 不得進入
  return。
- 截尾（跑滿 4200 且環境未 ``done``）：不是 terminal。Bootstrap 為
  **最後一次 ``env.step`` 之後** 的 observation 上、no-grad 重新前向
  得到的 ``V(s')``。Player 一步一 frame，該步折扣是 ``gamma * V(s')``。
- 禁止用 ``player_v1.gae`` 附上的 ``0.0`` 當截尾延續值。禁止用軌跡裡
  最後一個已存 value：那是發出最後一個 action 的 step 前 ``V(s_t)``，
  不是後繼狀態。
- 兩臂的 GAE、return 與 value target 都用這條規則。Knobs 必須明示
  bootstrap 開啟、截尾不當 terminal、截尾為 post-step ``V(s')``、真死
  為 0。Eval 的 4200 cap 與 censored elapsed 定義不變；bootstrap 只改
  訓練 target。

``entropy_coef=0.02``、``value_coef=0.5``、``ppo_epochs=4``、
``minibatch=512``、``max_grad_norm=1.0``、
``advantage_normalization=true``。Retention：
``phase2_ranked_multiseed.hybrid_loss``、hard/soft weight 0.5、

8、sampler／calibration／diagnostic seeds ``12345``／``22345``／
``32345``。這些 RNG 與 PPO minibatch permutation 分離。

Alpha 分臂校準
--------------

每臂在任何 optimizer step 之前，用該臂 update-1 rollouts（seeds
``210000``–``210007``）校準 **一次** 並凍結。校準與 update-1 PPO 重用
同一批 trajectories。公式：

``alpha = 0.15 * mean(||g_ppo||) / (mean(||g_ret||) + 1e-8)``

8 個 matched minibatch pairs；共同樣本數
``min(512, PPO frames, TRAIN frames)``。``g_ppo`` 只含該臂自己的
gamma、lambda 與 post-step bootstrap 所產生的 PPO policy gradient。

兩臂 alpha **分開計算、禁止互抄**。歷史 alpha
``0.38932983697041385`` 與任何 seed-11 confirmatory alpha 都不得預填。
不得按 eval、survival、agreement、KL、cosine 或中途曲線重調。

Primary endpoint
----------------

假說：在上述共同契約下，long 視野相對 control 視野，在預先鎖定的後段
matched survival 上有正的配對優勢。要回答的是存活時間。Teacher
agreement 是 secondary，不能單獨判定這項比較成功或失敗。

不得把 35 個時間相關 checkpoint 當成 35 個獨立實驗。

1. ``U = {3200, 3400, …, 10000}``，共 35 點。Primary 只用 U。
2. 對每個 eval seed ``s ∈ {3000,…,3029}``，
   ``d_s = (1/35) * Σ_{u∈U} (elapsed_long(u,s) − elapsed_control(u,s))``。
   Elapsed 是該 checkpoint 已寫入的 deterministic eval（秒），含 cap
   處 censored elapsed。
3. ``d̄ = mean_s d_s``。雙尾 95% CI，n=30 paired Student t：
   ``d̄ ± t_{0.975, 29} * s_d / sqrt(30)``，``s_d`` 為 30 個 ``d_s`` 的
   樣本標準差（分母 n−1）。分位數分析時計算，不在此手寫常數。
4. 只在整對 operationally complete 之後，只對 primary CI：
   - **support**：下界 > 0（long 的 seed-averaged 後段 elapsed 更高）；
   - **contrary**：上界 < 0；
   - **indeterminate**：CI 含 0。
5. 缺任一 ``u∈U`` 的任一種子 elapsed、checkpoint 對不齊、任一臂未完成、
   gamma／lambda／bootstrap 不符、或 eval seeds 不是精確的 3000–3029：
   **invalid**。禁止刪種子、改 U、或改用 n=35 的 checkpoint-mean 檢定。

每點另報 censor 數。Censor 不改 primary 公式。若兩臂 censor 結構明顯
不同，support 不得說成未截尾生存優勢。

資料來源：各臂 ``ppo_aux_update_{u}.pt`` packed
``extra.eval_summary.per_seed``；u<10000 的 U 點為 periodic model-only，
u10000 必須是含 teacher diagnostics 的 terminal full snapshot，
不是 periodic model-only。缺 per-seed
elapsed 則 fail closed；不得用 on-policy rollout mean 代替。允許事後用
同一權重、同一 3000–3029／4200 cap 重跑 eval 作核對；與 packed extra
衝突時以 packed extra 為 primary，差異寫入報告。

較長 survival 會中介更多 frames 與 optimizer steps。必須記帳，不得事後
解讀成相同 sample budget 下的純視野效果。
