Interpretation
--------------
1. PlayerV4's total capacity is not the blocker: the earlier tiny-set control
   overfit 2,000 teacher frames to 99.25% agreement.
2. The present single-query bullet-attention path is the dominant
   generalisation bottleneck in this controlled comparison. All attention arms
   plateaued near 0.40 while matched-parameter ranked flat8 arms reached
   0.65-0.70 on the same held set and update budget.
3. Merely reducing attention input from 64 to the nearest 8 bullets did not
   help. The likely issue is therefore not simple far-bullet dilution; it is
   more consistent with the aggregation/inductive-bias/optimisation path losing
   or struggling to learn ranked per-bullet geometry.
4. Hybrid hard+soft supervision matters after changing the representation:
   flat8_hybrid reached 0.695 agreement with KL 0.181, versus flat8_hard at
   0.649 agreement with KL 1.176.
5. Skill transfer is real but incomplete. The selected student recovered much
   of the teacher advantage and clearly beat flee, but the high 14.93-second
   closed-loop standard deviation and 7.88-second minimum show remaining
   fragile seeds.

Caveats
-------
- This is one training seed. The closed-loop result has 30 evaluation seeds,
  but training-seed variance has not yet been measured.
- Flat8_hybrid agreement is still 0.695, not near-perfect imitation.
- This isolates the current attention path versus ranked flat top-8 input; it
  does not prove that every possible attention architecture is unsuitable.
- The flat checkpoint is deliberately not load-compatible with production
  PlayerV4. It is evidence for the next architecture, not a promotion artifact.
