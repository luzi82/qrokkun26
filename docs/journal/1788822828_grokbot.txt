────────────────────────────────
v4.3 目標
────────────────────────────────
令評估可解釋、可重現、可分辨 policy vs env 隨機性，並用固定幾何 probe 量度 Spawner 瞄準／出生幾何有冇系統性死角（尤其右下角）。

包含
----
A. 三種 evaluation mode（互不混淆命名）

1. det_policy + det_env
   sample_policy=False, rng_jitter=False
   用途：除錯、純 network regression、檢查 deterministic collapse。

2. det_policy + stoch_env
   sample_policy=False, rng_jitter=True
   用途：learned Spawner 下 env seed 真正影響早期生成；robustness／選 ckpt 主指標之一。

3. stoch_policy + stoch_env
   sample_policy=True, rng_jitter=True
   每個 episode 用 torch.random.fork_rng() + manual_seed(episode_seed)，唔污染 train Torch RNG。
   用途：部署分布 sanity（可選，頻率低於 1/2）。

API 建議：
  eval_pair(..., sample_policy: bool, rng_jitter: bool) → 明確 metrics 名，例如
  new_vs_new_det_det / new_vs_new_det_stoch / flee_vs_newS_det_stoch …

正式 training-loop 報告至少同時打：
  - newP vs scripted（det_policy；scripted 本身用 env rng → seed 要 paired）
  - flee vs newS（mode 2 為主；mode 1 作對照）
  - new vs new（mode 1 同 mode 2 都記；唔好只用 mode 1 多 seed 當獨立樣本）

B. Paired unseen seeds
- 固定 seed 表（例如 30 個）跨模式、跨 matchup 共用。
- 報告 mean／median／std／n；可選分位數。
- 同一 seed 集合比較 run 之間差異。

C. 四角／邊界 probe（獨立 diagnostic，唔混進一般 seed mean）

固定 Player 位置集合（建議）：
- 中央
- 四角（含明確「右下角」）
- 四邊中點
共 1+4+4 = 9 點（可再加 ±margin 微擾一組，但 v4.3 最小集用 9）。

對每個位置：
- 凍結或分層 Spawner：deterministic policy（mean／argmax）為主；可選一輪 stoch_env jitter。
- 記錄：
  1. 首次命中時間（或 timeout）
  2. 命中率（多 trial／多 spawn steps）
  3. bullet 對 Player 嘅 closest approach（min distance over episode）
  4. Spawner birth／aim 輸出統計（birth 方向、aim offset 相對 Player）
- 分辨：policy exploit vs AIM_SCALE／tanh 飽和 vs birth ray 幾何／normalization bug。
- 輸出獨立 JSON／表，例如 runs/both_v4_corner_probe.json；唔併入 new×new mean。

D. Checkpoint／指標契約（輕量，完整 best-ckpt 管理仍屬 v4.6）
- 明文：new×new **唔做**唯一 selection metric。
- 建議暫時：
  - Player 觀察：newP vs scripted（paired，mode 清楚標註）
  - Spawner 觀察：flee vs newS（prefer det_policy+stoch_env）
- latest ckpt 照舊存；唔強制改 best 邏輯（留給 v4.6），但 log／docs 寫明。

E. Tests
1. eval_pair 三種 flag 組合行為：jitter True 時 early frames 消耗 env.rng（learned S）；False 時 8s 前可不耗（若 double-spawn 規則仍如此）——對齊既有結論寫 regression。
2. sample_policy=True 時 fork_rng：呼叫前後 global torch RNG state 不變。
3. 同一 (seed, mode) 可重現；不同 seed 喺 mode 2 下 flee/newS 或 newP/scripted 有可見差異（唔要求 new×new mode 1 有差異）。
4. Corner probe：9 個位置都喺 bounds；右下角 case 必跑；輸出 schema 穩定。
5. Normal reset eval 路徑同舊行為兼容（mode 1 對 scripted／既有呼叫點）。

F. Docs

- 新檔可選 docs/EVAL_MODES.md 短說明（若嫌 AGENT_VERSIONS 太長可只加一節）。
