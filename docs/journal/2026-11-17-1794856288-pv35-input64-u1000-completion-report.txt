Objective and model contract
Extend P actor/critic raw bullet input from 12 to 64 bullets plus their live
masks, while retaining teacher12 and clearance12 and the unchanged Pv34
harmless-bullet filter before stable distance ordering/top64 selection.
Each actor/critic input expands 84 -> 344: player6, raw bullets64x4, mask64,
clearance9 and safe flags9. Both heads retain hidden472, decoupled Tanh MLPs
and nine actions. Environment physics, reward, teacher/clearance algorithm,
PPO and Pv31 cuda_hoisted_single_stream backend remain unchanged.
This gives raw network access to up to 64 filtered candidates; it does not
mean the network sees every physical bullet, nor that teacher/clearance use64.

Initialization is a paired embedding of the exact saved Pv34 UNTRAINED random
u0 realization (initialization seed17), not trained best/terminal weights.
For both first layers, old player/bullet columns0:54 map to0:54,
mask54:66 to262:274, clearance66:84 to326:344. Additional raw54:262 and
mask274:326 columns start at zero; later weights/biases are copied exactly.
This uses old fan_in84 initialization, not native fan_in344 initialization;
new columns can subsequently learn. Exact mapped weights do not assert
bit-identical expanded-GEMM logits or trajectories. Both Adam optimizers are
fresh. The inherited old trained-player CLI path is unused provenance only,
never a learner warm start. Frozen stochastic CPU Sv24 best u980 is unchanged.
